# news-image-20261123

One image summing up 23 November's world news.

`main.py` (Python 3, standard library only) draws a 1024x1024 poster — masthead naming Monday 23 November 2026, six story cards, and a sources footer — and writes it to `out/entry.png` (or `$MAKEFUN_OUTPUT_DIR/entry.png`). Run it twice: the output bytes are identical.

The six stories, all first reported on 23 November 2026:

1. COP31 talks break down — AP / Helsinki Times
2. Democrats win 258 House seats — AP
3. Nepal PM holds talks with Modi — Observer Voice
4. Anthropic IPO valued at $1.5T — AP
5. US loses measles-free status — AP
6. India post 720-9 in the Wellington Test — Observer Voice
